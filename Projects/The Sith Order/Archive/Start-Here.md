# A fresh start

This collection preserves the first exploration of The Sith Order. The archived drafts are reference material, not binding doctrine or adopted organizational rules. There is currently one founder; community structures can wait until experience makes them useful.

- [[Provisional-Founding-Statement-Archived]] — reviewed founding vision, version 0.1.
- [[The-Sith-Code---Commentary-Archived]] — accepted working interpretation, version 0.1.
- [[Roadmap-Archived]] — original roadmap, superseded by the decision to begin with lived practice.
- [[The-Sith-Order---Charter-Archived]] — the supplied file contains only a version line; see [[Discussion-Notes]] for the exploratory charter ideas.

## Begin again

Walk the path personally. Explore, reflect, and record what happens. Let practices and meanings develop through experience. No schedule, prescribed ritual, or new system of ranks is established here.

Start with [[Founders-Journal]]. Return to the archive whenever useful, and revise ideas consciously rather than treating earlier drafts as obligations.
