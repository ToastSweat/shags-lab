# TRANSMISSION 006C [Jedicide, Shadows of the Empire [3]]

Third pass.

I didn’t change anything.

Same source. Same Anchor. Same dial position. Same television settings. I rebuilt everything from the notes again and let the receiver settle.

The song came back.

So did another version of it.

That makes three.

At this point I’m comfortable saying the experiment worked. Just not in the way I expected.

The settings are repeatable. The result isn’t.

006A, 006B, and this one all occupy the same little neighborhood I’ve been tuning into, but they are not the same recording. Whatever the controls are doing, they seem to narrow the possibilities without selecting a single one.

That is useful.

It is also a little difficult to think about.

Because if I can reset the receiver and keep getting another valid version of the same song, I don’t know what would make that stop.

Maybe there are only a handful.

Maybe there are thousands.

Maybe asking how many is already the wrong question.

I almost reset it a fourth time.

Instead I wrote this down and walked away.

For now.
