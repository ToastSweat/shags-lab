# TRANSMISSION 006B [Jedicide, Shadows of the Empire [2]]

Second pass.

I reset the receiver, rebuilt the settings from my notes, and checked everything twice before I started. Same source. Same Anchor. Same dial position. Same television settings.

The signal came back. The song came back.

006A did not.

This version is close enough that I’m not willing to call it random. Same structure. Same identity. Same neighborhood, if that’s the right word. But the performance is different again.

That rules out one of my assumptions. These controls aren’t coordinates. If they were, I should be able to return to 006A.

Maybe Anchor, Drift, and Depth don’t describe a location. Maybe they describe a range of possibilities the receiver can reach.

That leaves a more interesting question: once I’m inside that range, what determines which version I actually get?

I don’t know.

So I’m not changing anything yet. I’m going to reset it and do the exact same thing one more time.
