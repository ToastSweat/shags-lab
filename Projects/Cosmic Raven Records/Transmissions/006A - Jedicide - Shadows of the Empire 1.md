# TRANSMISSION 006A [Jedicide, Shadows of the Empire [1]]

[Watch on YouTube](https://www.youtube.com/watch?v=RO-x8LIJHb4)

I wanted one clean experiment.

No wandering. No chasing a fragment just because something in the static caught my attention. Same source, same Anchor, same dial position, same television settings. I wrote everything down before I started.

The first pass was almost boring. The signal came in quickly. Stable picture. Clean audio. The song was right where I expected it to be.

I recorded it and thought, for once, maybe I was finally getting somewhere.

Then I shut the receiver down.

I reset everything, waited a while, and rebuilt the settings from my notes as carefully as I could.

I expected to find this recording again.

I didn’t.

I found the song. Same structure. Same identity. Close enough that I knew immediately I was in the right neighborhood.

But it wasn’t the same performance.

Different choices. Different details. Not dramatic, but unmistakable.

That should not happen if these controls are coordinates.

If I can put every knob back where it was and still arrive somewhere else, then either I’m missing a variable or the receiver does not work the way I’ve been assuming.

Maybe the settings don’t tell the receiver where to go.

Maybe they only tell it what kind of place to look for.

I don’t know yet.

So this is the first recording from the test.

I’m calling it 006A because I already know it isn’t alone.
