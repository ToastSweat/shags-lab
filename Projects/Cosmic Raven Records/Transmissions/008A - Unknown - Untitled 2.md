# TRANSMISSION 008A [Unknown, Untitled 2]

I tried to find another stranger.

That is apparently a sentence I can write now.

I started from the settings around 007A. Anchor at zero again. Same general range of Drift and Depth, but I wasn't trying to recover the same signal.

I wanted to know if 007A was a fluke.

It wasn't.

This one came in faster.

A little static at first, then a rhythm, then the whole thing locked into place.

Different song.

Different voice.

Different everything.

But there was something familiar about the shape of it.

Not familiar like I'd heard it before.

Familiar like it belonged near 007A.

I don't know how else to explain that without pretending I understand more than I do.

The receiver has already taught me that the controls don't point to one exact result. They narrow things down.

Maybe they narrow down more than a range of versions.

Maybe they narrow down a kind of signal.

A mood.

A sound.

A set of choices.

I've started marking these areas in my notes.

Not because I think I've mapped anything.

Mostly because I want to know if I can come back tomorrow and find something else that feels like it belongs here.

And, honestly, because this is fun now.

That might be the strangest part.

A few weeks ago I was worried every time I turned this thing on.

Tonight I spent two hours chasing a synth line through static because I wanted to hear where it went.

I found it.

Then I kept looking.
