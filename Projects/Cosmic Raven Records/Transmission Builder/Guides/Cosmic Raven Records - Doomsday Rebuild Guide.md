# Cosmic Raven Records - Doomsday Rebuild Guide

If you are reading this because the original machine died, Windows was reinstalled, the Dropbox folder vanished, or Future Me has absolutely no memory of how any of this worked: hello.

This is how to rebuild the Cosmic Raven Records transmission-video workflow from scratch.

## What this system actually does

You give one BAT file four things:

```text
song file
transmission number
artist
track title
```

It uses FFmpeg to create:

1. a five-second acquisition intro,
2. the song beginning after that intro,
3. a 1920x1080 static-background transmission video with HUD text and an audio spectrum,
4. a 1280x720 YouTube thumbnail,
5. clean-ish filenames based on transmission / artist / title.

The current narrative descriptions are **not** generated by the BAT. Those live in the Google Doc `Cosmic Raven Records - Transmission Script`.

## 1. Rebuild the folder

Use something like:

```text
Cosmic Raven Records\
├── make_transmission.v4.bat
├── assets\
│   ├── background_1.png
│   ├── intro_background_1.png
│   ├── intro.wav
│   ├── hud_overlay.png
│   ├── intro_overlay.png
│   └── thumbnail_overlay.png
├── output\
├── docs\
└── archive\
```

The production project used:

```text
D:\Dropbox\[COSMIC RAVEN, LLC]\[RECORDS]
```

It does not have to live there, because the BAT works relative to its own location.

---

## 2. Install FFmpeg

On Windows, the original setup used the Gyan FFmpeg build installed through WinGet.

```powershell
winget install Gyan.FFmpeg
```

Close and reopen the terminal, then verify:

```powershell
ffmpeg -version
```

The workflow was built around FFmpeg 9.x, but it uses ordinary filters and should not require exactly that build forever.

---

## 3. Font requirement

The current BAT uses Windows Consolas:

```text
C:\Windows\Fonts\consola.ttf
```

In the FFmpeg filter string the path appears as:

```text
C\:/Windows/Fonts/consola.ttf
```

If that font disappears in a future Windows version, replace the `FONT` variable with another monospaced font path.

## 4. Restore the assets

The exact expected filenames are:

```text
background_1.png
intro_background_1.png
intro.wav
hud_overlay.png
intro_overlay.png
thumbnail_overlay.png
```

Important: the raven logo is baked into the current overlays. Old prototypes used a separate `logo.png`; the current baseline does not.

If `intro_background_1.png` is missing, the script falls back to `background_1.png`.

All PNGs should be designed for a 1920x1080 canvas even though FFmpeg will scale them.

## 5. Run a test

Put a test WAV beside the BAT and run:

```bat
make_transmission.v4.bat "Test.wav" "999A" "Test Artist" "Test Track"
```

Expected output:

```text
output\CRR_999A_Test_Artist_Test_Track.mp4
output\CRR_999A_Test_Artist_Test_Track_thumbnail.png
```

The exact filename sanitizer is intentionally simple in this baseline, so weird punctuation is worth testing before a real release.

## 6. How the audio works

The reliable version does **not** try to fake a five-second intro by merely delaying the song inside one complicated filter graph.

It first creates a temporary WAV:

```text
0:00 - 0:05  assets\intro.wav
0:05 - end   selected song
```

That combined WAV becomes the final MP4 audio and also feeds the visualizer.

This solved earlier synchronization/introduction problems and is an important part of the known-good baseline.

## 9. Progress output

Do not go back to raw FFmpeg `-stats` unless you enjoy watching Windows Terminal vomit wrapping progress lines forever.

The working version uses:

```text
-nostats
-progress pipe:1
```

and PowerShell converts the machine-readable progress stream into one updating console line.

FFmpeg errors are redirected to a temporary error file and displayed only when rendering fails.

## 10. Windows BAT landmines discovered the annoying way

### Parentheses in filenames

Windows CMD can misparse filenames like:

```text
Empty (Cover).wav
```

when variables are expanded inside parenthesized command blocks.

The safer pattern is labels + `goto` for validation/error handling.

### FFmpeg drawtext colons

Literal colons inside `drawtext` need escaping:

```text
SIGNAL\:
```

### BAT continuation characters

A `^` must be the final character on its line. Trailing spaces after it can break the command.

### Single PNG output

Use:

```text
-frames:v 1 -update 1
```

### Filter graphs

Do not try to use a simple `-vf` and a conflicting `-filter_complex` pipeline for the same output. Keep scaling/compositing inside the complex graph when needed.

### Receiver timer

A `%%{pts\:hms}` receiver timer was tried and removed. Do not resurrect it unless there is a compelling reason.

## 11. Transmission numbering

The format is:

```text
001A
002A
002B
003A
004A
004B
005B
006A
...
```

The number refers to an underlying song / signal / experiment.

The letter identifies a stable recovered version.

A and B are **not proven coordinates**. They are archive labels.

005A was deliberately skipped in the public archive. Do not “fix” the numbering.

## 14. If everything is gone

Recovery order:

1. Clone the Git repository.
2. Restore the live `assets` folder.
3. Install FFmpeg.
4. Verify Consolas or change the font path.
5. Run the `999A` test render.
6. Restore/export the Google Doc narrative archive.
7. Compare output against an old YouTube transmission.
8. Only then start changing things.

If the original production assets are gone, use an old rendered transmission as the visual reference and rebuild new overlays at 1920x1080. The fiction does not require pixel-perfect preservation of the old HUD; the generator only requires the expected files to exist.
