# Shag's Lab: The Doomsday Rebuild Guide

This is the file for Future Me, Curious You, or Whoever Is Looking At A Dead PC Wondering Why A Personal Wiki Needed A Build Pipeline.

The short version:

**The Obsidian vault is the source of truth.**

Everything else is replaceable.

The live site is a static Quartz build made from explicitly public notes in that vault. The vault and generated site live in one private Git repository. The home PC builds and pushes it. The web host pulls it and copies only the finished public files into Apache's web root.

If every piece of software involved in this project vanished tomorrow, the important part would still be a folder full of Markdown files and images.

That is the point.

## The content model

Do not overcomplicate this.

There are two main things:

- **Updates** are chronological diary entries.
- **Projects** are persistent wiki-ish things.

An Update should normally have:

```yaml
---
type: update
date: 2026-09-19
project: Exact Project Name
publish: true
---
```

A Project Home should normally have:

```yaml
---
type: project
project: Exact Project Name
status: active
publish: true
---
```

The `project:` value on the Project Home and its Updates should match.

That is how the publisher knows which Updates belong to which Project and can sort Projects by recent activity.

The homepage should contain:

```yaml
---
title: Welcome
publish: true
---
```

`Updates/Updates Home.md` and `Projects/Projects Home.md` are generated by the publisher.

**Do not lovingly hand-maintain those lists. The script will overwrite them.**

Anything without:

```yaml
publish: true
```

stays out of the public build.

`Work/` and `Queued Projects/` are always excluded, even when a note inside them says `publish: true`. That includes attachments. Public notes can still mention those projects, but private-note links become plain text in the website staging copy. The original Obsidian links stay intact.

## Normal publishing workflow

On the home PC:

1. Work normally in Obsidian.
2. Add/update notes.
3. Set `publish: true` only on things that should be public.
4. Run `Publish-ShagsLab-HomePC.bat`.

That BAT runs the PowerShell publisher.

The publisher:

1. Scans the vault.
2. Generates `Updates Home`.
3. Generates `Projects Home`.
4. Creates a clean Quartz staging directory.
5. Copies only published notes.
6. Copies assets referenced by published notes.
7. Turns `Welcome.md` into `index.md`.
8. Builds Quartz.
9. Mirrors the built static site into `.site\public` inside the vault repository.
10. Commits the vault and generated site.
11. Pushes `main` to GitHub.

Then, on the web host, run:

```text
Update-ShagsLab-WebHost.bat
```

That:

1. Pulls `origin/main`.
2. Verifies `.site\public\index.html` exists.
3. Mirrors `.site\public` into `C:\xampp\htdocs\helvete\lab`.

Done.

- npm

```text

```

```powershell

```

Clone the private repo:

```powershell

```

Because `[DIARY]` contains square brackets, use PowerShell's literal-path commands when navigating:

```powershell
Set-Location -LiteralPath "F:\[DIARY]\Shag's Lab"
```

Do not rely on:

```powershell

```

PowerShell may interpret the brackets as a wildcard pattern.

Open `F:\[DIARY]\Shag's Lab` as an Obsidian vault.

### 3. Recreate Quartz

Clone Quartz beside the vault:

```powershell
git clone https://github.com/jackyzha0/quartz.git "F:\[DIARY]\ShagsLab-Web"
Set-Location -LiteralPath "F:\[DIARY]\ShagsLab-Web"
npm i
```

Initialize it for Obsidian:

```powershell
npx quartz create --template obsidian --strategy new --baseUrl helvete.pizza/lab
```

If Quartz complains that the default theme exists but cannot be loaded:

```text
Cannot find module '@quartz-themes/default'
```

install it explicitly:

```powershell
npm install @quartz-themes/default
```

In `quartz.config.yaml`, make sure the important values are:

```yaml

  pageTitle: "Shag's Lab"
  baseUrl: "helvete.pizza/lab"
```

The custom publisher performs the public/private filtering before Quartz sees the notes, so the Quartz `explicit-publish` plugin does not need to be enabled.

The [saved Quartz configuration](Projects/Obsidian%20Vault%20to%20Website/assets/quartz.config.housekeeping.yaml) also preserves the private-folder ignore patterns and the Updates-only newest-first Explorer sort. Restore those settings as well when rebuilding; the two `pageTitle`/`baseUrl` values above are not the whole configuration.

Updates Home sorts by the post date, newest first, with the numbered filename suffix breaking same-day ties. Explorer uses that filename chronology too, rather than the last time a note was edited. The rest of Explorer stays alphabetic.

Restore `Publish-Lab.ps1` from the copy embedded later in this guide.

Save it as:


## Metadata troubleshooting

If an Update does not appear on `Updates Home`, verify:

```yaml
type: update
date: YYYY-MM-DD
publish: true
```

If a Project does not sort based on its newest Update, verify the Project Home and Update use exactly the same `project:` value.

Example:

Project Home:

```yaml
project: Keychron C100
```

Update:

```yaml
project: Keychron C100
```

If they differ, the generator treats them as different projects.

If a note appears in Obsidian but not publicly, verify it has:

```yaml
publish: true
```

That omission is a feature, not a bug.

### Homepage is a 404

Quartz expects:

```text

```

The publisher creates it from `Welcome.md`.

Verify `Welcome.md` contains:

```yaml
---

```

### Homepage is titled `index`

Same issue: make sure the `title: Welcome` frontmatter is present before building.

### Explorer is empty and Graph View is one dot

Quartz has only received one note, usually because `content` was manually populated incorrectly.

Do not manually maintain `ShagsLab-Web\content`.

Run the publisher so it regenerates the staging directory from the vault.

### `@quartz-themes/default` cannot be found

From:

```text
F:\[DIARY]\ShagsLab-Web
```

run:

```powershell
npm install @quartz-themes/default
```

then rebuild.

### Windows PowerShell throws bizarre parse errors around normal code

The publisher must remain safe for Windows PowerShell 5.1.

The original failure came from a Unicode em dash in a UTF-8-without-BOM `.ps1`, which PowerShell misread and then produced a cascade of nonsense parser errors.

Keep the operational publisher script ASCII-only unless PowerShell encoding behavior is deliberately changed.

## The actual backup philosophy

There are several layers here and they have different jobs:

```text
Obsidian vault
    = original source

Local Git
    = local history

Private GitHub
    = off-machine copy + transport

.site\public
    = generated website snapshot

Web host checkout
    = deploy source

Apache lab folder
    = disposable live copy
```

The most important data is always:

```text
F:\[DIARY]\Shag's Lab
```

If the website disappears, rebuild it.

If Apache disappears, rebuild it.

If Quartz disappears, replace it with something else.

Do not contort the vault around the website.

The website exists to present the vault.

The vault does not exist to feed the website.

```powershell
$ErrorActionPreference = "Stop"

function Write-Step {
    param([string]$Message)
    Write-Host ""
    Write-Host "==> $Message" -ForegroundColor Cyan
}

function Write-Utf8NoBom {
    param(
        [string]$Path,
        [string]$Text
    )
    $parent = Split-Path -Parent $Path
    if ($parent -and -not (Test-Path -LiteralPath $parent)) {
        New-Item -ItemType Directory -Path $parent -Force | Out-Null
    }
    $utf8 = New-Object System.Text.UTF8Encoding($false)
    [System.IO.File]::WriteAllText($Path, $Text, $utf8)
}

function Get-RelativePathFromRoot {
    param(
        [string]$Root,
        [string]$FullPath
    )
    $rootNormalized = $Root.TrimEnd('\')
    if (-not $FullPath.StartsWith($rootNormalized, [System.StringComparison]::OrdinalIgnoreCase)) {
        throw "Path '$FullPath' is not inside '$Root'."
    }
    return $FullPath.Substring($rootNormalized.Length).TrimStart('\')
}

# Folder privacy is an unconditional source boundary, not frontmatter metadata.
# Share it between both note scans, the asset index and direct asset resolution.
function Test-PublicSourcePath {
    param([string]$FullPath)

    $root = [System.IO.Path]::GetFullPath($VaultPath).TrimEnd('\', '/') + '\'
    $candidate = [System.IO.Path]::GetFullPath($FullPath)
    if (-not $candidate.StartsWith($root, [System.StringComparison]::OrdinalIgnoreCase)) {
        return $false
    }
    $relative = $candidate.Substring($root.Length) -replace '\\', '/'
    return $relative -notmatch '^(?i:Work|Queued Projects)(/|$)' -and
        $relative -notmatch '(^|/)(?i:\.git|\.obsidian|\.trash|\.site)(/|$)'
}

function Get-FrontMatter {
    param([string]$Text)

    $result = @{}
    $normalized = $Text -replace "`r`n", "`n"

    if (-not $normalized.StartsWith("---`n")) {
        return $result
    }

    $end = $normalized.IndexOf("`n---`n", 4)
    if ($end -lt 0) {
        return $result
    }

    $block = $normalized.Substring(4, $end - 4)
    $aliasList = $false

    foreach ($line in ($block -split "`n")) {
        if ($line -match '^\s*([A-Za-z0-9_-]+)\s*:\s*(.*?)\s*$') {
            $key = $Matches[1].ToLowerInvariant()
            $value = $Matches[2].Trim()

            if (($value.StartsWith('"') -and $value.EndsWith('"')) -or
                ($value.StartsWith("'") -and $value.EndsWith("'"))) {
                $value = $value.Substring(1, $value.Length - 2)
            }

            $result[$key] = $value
            # Obsidian writes aliases as a block sequence. Keep project and
            # project_aliases on their existing comma/pipe scalar contracts.
            $aliasList = $key -eq 'aliases' -and $value -eq ''
            if ($aliasList) { $result[$key] = @() }
        }
        elseif ($aliasList -and $line -match '^\s*-(?:\s+(.*?))?\s*$') {
            $value = ([string]$Matches[1]).Trim()
            if ($value -match '^(["''])(.*?)\1(?:\s+#.*)?$') {
                $value = $Matches[2]
            }
            else { $value = ($value -replace '(^|\s+)#.*$', '').Trim() }
            $result['aliases'] += @($value)
        }
        elseif ($line -notmatch '^\s*(#.*)?$') { $aliasList = $false }
    }

    return $result
}

function Get-PrivateProjectReferenceKeys {
    # This local-only metadata registry lets a public update name an existing
    # private project. No private note enters validation, indexes or staging.
    $keys = @{}
    foreach ($folder in @('Work', 'Queued Projects')) {
        $directory = Join-Path $VaultPath $folder
        if (-not (Test-Path -LiteralPath $directory -PathType Container)) { continue }
        foreach ($file in (Get-ChildItem -LiteralPath $directory -Recurse -File -Filter '*.md')) {
            $reader = [IO.File]::OpenText($file.FullName)
            try {
                if ($reader.ReadLine() -ne '---') { continue }
                $lines = New-Object System.Collections.Generic.List[string]
                $lines.Add('---')
                while ($null -ne ($line = $reader.ReadLine())) {
                    $lines.Add($line)
                    if ($line -eq '---') { break }
                }
                $fm = Get-FrontMatter -Text (($lines -join "`n") + "`n")
                if ($fm['type'] -notin @('project', 'project-parent')) { continue }
                if ($fm['project']) { $keys[$fm['project'].Trim().ToLowerInvariant()] = $true }
                foreach ($alias in ($fm['project_aliases'] -split '\|')) {
                    if ($alias.Trim()) { $keys[$alias.Trim().ToLowerInvariant()] = $true }
                }
            }
            finally { $reader.Dispose() }
        }
    }
    return $keys
}

function Get-BodyAfterFrontMatter {
    param([string]$Text)

    $normalized = $Text -replace "`r`n", "`n"

    if (-not $normalized.StartsWith("---`n")) {
        return $normalized
    }

    $end = $normalized.IndexOf("`n---`n", 4)
    if ($end -lt 0) {
        return $normalized
    }

    return $normalized.Substring($end + 5)
}

function Convert-ToDate {
    param([string]$Value)

    if ([string]::IsNullOrWhiteSpace($Value)) {
        return [datetime]::MinValue
    }

    try {
        return [datetime]::Parse($Value, [System.Globalization.CultureInfo]::InvariantCulture)
    }
    catch {
        return [datetime]::MinValue
    }
}

function Get-ProjectKeysFromUpdate {
    param([string]$ProjectValue)

    if ([string]::IsNullOrWhiteSpace($ProjectValue)) {
        return @()
    }

    # Supports the current simple format:
    # project: Keychron C100
    # project: BASS VI - Penny, GitHub
    return @(
        $ProjectValue -split ',' |
        ForEach-Object { $_.Trim() } |
        Where-Object { $_ }
    )
}

function Get-WikiTarget {
    param([string]$RawTarget)

    $target = $RawTarget.Trim()

    if ($target.Contains('|')) {
        $target = $target.Split('|')[0]
    }
    if ($target.Contains('#')) {
        $target = $target.Split('#')[0]
    }

    return $target.Trim()
}

function Get-PublicationLinkKey {
    param([string]$Target)
    $clean = Get-WikiTarget -RawTarget $Target
    $clean = [uri]::UnescapeDataString($clean.Trim('<', '>')) -replace '\\', '/'
    return ($clean -replace '\.md$', '').TrimStart('/').ToLowerInvariant()
}

function Test-PrivateLinkTarget {
    param([string]$Target, [string]$NoteDirectory)
    if ($Target -match '^[a-zA-Z][a-zA-Z0-9+.-]*:|^#|^//') { return $false }
    $key = Get-PublicationLinkKey -Target $Target
    if (-not $key) { return $false }
    if ($privateLinkTargets.ContainsKey($key)) { return $true }
    foreach ($base in @($NoteDirectory, $VaultPath)) {
        $candidate = [IO.Path]::GetFullPath((Join-Path $base ($key -replace '/', '\')))
        if (-not (Test-PublicSourcePath -FullPath $candidate)) { return $true }
        $relative = Get-RelativePathFromRoot -Root $VaultPath -FullPath $candidate
        if ($privateLinkTargets.ContainsKey(($relative -replace '\\', '/').ToLowerInvariant())) { return $true }
    }
    return $false
}

function Get-MarkdownCodePattern {
    return '(?ms)^[ \t]*(?<fence>`{3,}|~{3,})[^\r\n]*\r?\n.*?^[ \t]*\k<fence>[ \t]*(?:\r?\n|$)|(?<inline>`+)[^\r\n]*?\k<inline>(?!`)'
}

function Convert-ToPublicStagingText {
    param([string]$Text, [string]$NoteDirectory)
    # Remove the link token before Quartz parses it: unresolved wikilinks still
    # produce hrefs and graph links. Source notes remain byte-for-byte untouched.
    # Code examples are not links; protect them before applying link patterns.
    $codeSlots = @{}
    $codePrefix = 'SHAGSLAB_CODE_' + [guid]::NewGuid().ToString('N') + '_'
    $codeEvaluator = [System.Text.RegularExpressions.MatchEvaluator]{ param($match)
        $slot = $codePrefix + $codeSlots.Count + '_END'
        $codeSlots[$slot] = $match.Value
        return $slot
    }
    $codePattern = Get-MarkdownCodePattern
    $maskedText = [regex]::Replace($Text, $codePattern, $codeEvaluator)
    $wikiEvaluator = [System.Text.RegularExpressions.MatchEvaluator]{ param($match)
        $raw = $match.Groups[1].Value
        if (-not (Test-PrivateLinkTarget -Target $raw -NoteDirectory $NoteDirectory)) { return $match.Value }
        $display = if ($raw.Contains('|')) { $raw.Substring($raw.IndexOf('|') + 1) }
            else { (([uri]::UnescapeDataString((Get-WikiTarget -RawTarget $raw)) -replace '\\', '/') -replace '\.md$', '').Split('/')[-1] }
        return [regex]::Replace($display, '([\\`*{}\[\]<>()!])', '\$1')
    }
    $result = [regex]::Replace($maskedText, '!?\[\[([^\]]+)\]\]', $wikiEvaluator)
    $markdownEvaluator = [System.Text.RegularExpressions.MatchEvaluator]{ param($match)
        $target = $match.Groups[2].Value.Trim()
        # Markdown URL may be enclosed in angle brackets or followed by a title.
        if ($target.StartsWith('<')) { $target = ($target -split '>')[0].TrimStart('<') }
        else { $target = $target -replace '\s+["''].*$', '' }
        if (-not (Test-PrivateLinkTarget -Target $target -NoteDirectory $NoteDirectory)) { return $match.Value }
        return [regex]::Replace($match.Groups[1].Value, '([\\`*{}\[\]<>()!])', '\$1')
    }
    $result = [regex]::Replace($result, '!?\[([^\]\r\n]*)\]\(([^)\r\n]+)\)', $markdownEvaluator)
    foreach ($entry in $codeSlots.GetEnumerator()) { $result = $result.Replace($entry.Key, $entry.Value) }
    return $result
}

function Set-FrontMatterScalar {
    param(
        [string]$Text,
        [string]$Key,
        [string]$Value
    )

    $normalized = $Text -replace "`r`n", "`n"

    if (-not $normalized.StartsWith("---`n")) {
        return "---`n$Key`: $Value`n---`n" + $normalized
    }

    $end = $normalized.IndexOf("`n---`n", 4)
    if ($end -lt 0) {
        return $normalized
    }

    $front = $normalized.Substring(4, $end - 4)
    $rest = $normalized.Substring($end + 5)

    $pattern = "(?m)^\s*" + [regex]::Escape($Key) + "\s*:.*$"
    if ([regex]::IsMatch($front, $pattern)) {
        $front = [regex]::Replace($front, $pattern, "$Key`: $Value", 1)
    }
    else {
        if ($front.Length -gt 0 -and -not $front.EndsWith("`n")) {
            $front += "`n"
        }
        $front += "$Key`: $Value"
    }

    return "---`n" + $front.TrimEnd("`n") + "`n---`n" + $rest
}

function Resolve-Attachment {
    param(
        [string]$Target,
        [string]$NoteDirectory
    )

    $clean = Get-WikiTarget -RawTarget $Target
    if ([string]::IsNullOrWhiteSpace($clean)) {
        return $null
    }

    if ($clean -match '^[a-zA-Z][a-zA-Z0-9+.-]*://') {
        return $null
    }

    $cleanFs = $clean -replace '/', '\'

    $sameFolder = Join-Path $NoteDirectory $cleanFs
    if (Test-Path -LiteralPath $sameFolder -PathType Leaf) {
        $item = Get-Item -LiteralPath $sameFolder
        if (-not (Test-PublicSourcePath -FullPath $item.FullName)) {
            return $null
        }
        if ($item.Extension -ine ".md") {
            return $item
        }
    }

    $fromRoot = Join-Path $VaultPath $cleanFs
    if (Test-Path -LiteralPath $fromRoot -PathType Leaf) {
        $item = Get-Item -LiteralPath $fromRoot
        if (-not (Test-PublicSourcePath -FullPath $item.FullName)) {
            return $null
        }
        if ($item.Extension -ine ".md") {
            return $item
        }
    }

    $leaf = Split-Path -Leaf $cleanFs
    if ($assetsByName.ContainsKey($leaf.ToLowerInvariant())) {
        $matches = @($assetsByName[$leaf.ToLowerInvariant()])
        if ($matches.Count -gt 1) {
            Write-Warning "Attachment '$clean' is ambiguous; using '$($matches[0].FullName)'."
        }
        return $matches[0]
    }

    return $null
}

Write-Host "Base path: $ExpectedBasePath"

Write-Step "Adding visible GoatCounter visitor counter"

$visitorCounterLabel = "Shag's Lab"

$visitorCounterJs = @'
(function () {
  async function updateVisitorCounter() {
    var nodes = document.querySelectorAll("[data-shags-visitor-count]");
    if (!nodes.length) return;

    try {
      var response = await fetch("/lab/visitor-count.php", {
        cache: "no-store",
        credentials: "same-origin"
      });

      if (!response.ok) {
        throw new Error("Visitor counter endpoint returned HTTP " + response.status);

      if (!data || typeof data.count === "undefined") {
        throw new Error("Visitor counter endpoint returned no count.");
      }

      nodes.forEach(function (node) {
        node.textContent = data.count;
      });
    } catch (error) {
      console.warn("Shag's Lab visitor counter could not be loaded.", error);
      nodes.forEach(function (node) {
        node.textContent = "--";
      });
    }
  }

    window.setTimeout(updateVisitorCounter, 0);
  }

  if (document.readyState === "loading") {
    document.addEventListener("DOMContentLoaded", updateVisitorCounter, { once: true });
  } else {
    updateVisitorCounter();

})();

.shags-lab-visitor-counter {

$visitorProxyPhp = @'
<?php
header('Content-Type: application/json; charset=utf-8');
header('Cache-Control: public, max-age=300');

$url = 'https://shagwrath.goatcounter.com/counter/TOTAL.json';
$body = false;

if (function_exists('curl_init')) {
    $curl = curl_init($url);

    curl_setopt_array($curl, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_FOLLOWLOCATION => true,
        CURLOPT_CONNECTTIMEOUT => 5,
        CURLOPT_TIMEOUT => 10,
        CURLOPT_USERAGENT => 'ShagsLab-VisitorCounter/1.0',
    ]);

    $body = curl_exec($curl);
    $status = (int) curl_getinfo($curl, CURLINFO_RESPONSE_CODE);
    curl_close($curl);

    if ($body === false || $status < 200 || $status >= 300) {
        $body = false;
    }
}
elseif (filter_var(ini_get('allow_url_fopen'), FILTER_VALIDATE_BOOLEAN)) {
    $context = stream_context_create([
        'http' => [
            'timeout' => 10,
            'header' => "User-Agent: ShagsLab-VisitorCounter/1.0\r\n",
        ],
    ]);

    $body = @file_get_contents($url, false, $context);
}

if ($body === false) {
    http_response_code(502);
    echo json_encode(['error' => 'Unable to reach GoatCounter']);
    exit;
}

$data = json_decode($body, true);

if (!is_array($data) || !array_key_exists('count', $data)) {
    http_response_code(502);
    echo json_encode(['error' => 'Invalid GoatCounter response']);
    exit;
}

echo json_encode([
    'count' => (string) $data['count'],
]);
'@

$visitorMarkup = '<div class="shags-lab-visitor-counter"><strong>' +
    [System.Net.WebUtility]::HtmlEncode($visitorCounterLabel) +
    '</strong> &middot; <span data-shags-visitor-count>...</span><span>visitors</span></div>'

$patchedPages = 0
$pagesWithoutFooter = New-Object System.Collections.Generic.List[string]

foreach ($htmlFile in $htmlFiles) {
    $html = [System.IO.File]::ReadAllText($htmlFile.FullName, [System.Text.Encoding]::UTF8)
    $changed = $false

    if (-not $html.Contains("shags-visitor-counter.css") -and $html.Contains("</head>")) {
        $html = $html.Replace("</head>", $visitorStyleTag + "</head>")
        $changed = $true
    }

    if (-not $html.Contains("data-shags-visitor-count")) {
        if ($html.Contains("</footer>")) {
            $html = $html.Replace("</footer>", $visitorMarkup + "</footer>")
            $changed = $true
        }
        else {
            $pagesWithoutFooter.Add($htmlFile.FullName)
        }
    }

    if (-not $html.Contains("shags-visitor-counter.js") -and $html.Contains("</body>")) {
        $html = $html.Replace("</body>", $visitorScriptTag + "</body>")
        $changed = $true
    }

    if ($changed) {
        Write-Utf8NoBom -Path $htmlFile.FullName -Text $html
        $patchedPages++
    }
}

Write-Host "Visible counter added to $patchedPages HTML page(s)."
Write-Host "Visitor count is proxied through /lab/visitor-count.php to avoid browser CORS restrictions."

if ($pagesWithoutFooter.Count -gt 0) {
    Write-Host "Pages without a footer were left without the visible counter: $($pagesWithoutFooter.Count)"
}

$counterCheck = [System.IO.File]::ReadAllText($builtIndex, [System.Text.Encoding]::UTF8)

if (-not $counterCheck.Contains("data-shags-visitor-count")) {
    throw "Visitor counter markup was not found in the built homepage after patching."
}

if (-not $counterCheck.Contains("shags-visitor-counter.js")) {
    throw "Visitor counter script was not found in the built homepage after patching."
}

if (-not (Test-Path -LiteralPath $visitorProxyPath -PathType Leaf)) {
    throw "Visitor counter PHP proxy was not created: $visitorProxyPath"
}

Write-Host "Visitor counter endpoint: https://helvete.pizza/lab/visitor-count.php"

Write-Step "Copying built website into the same Git repo"

$trackedParent = Split-Path -Parent $TrackedSiteRoot
if (-not (Test-Path -LiteralPath $trackedParent)) {
    New-Item -ItemType Directory -Path $trackedParent -Force | Out-Null
}

if (-not (Test-Path -LiteralPath $TrackedSiteRoot)) {
    New-Item -ItemType Directory -Path $TrackedSiteRoot -Force | Out-Null
}

& robocopy $PublicRoot $TrackedSiteRoot /MIR /R:2 /W:1 /NFL /NDL /NP
$robocopyExit = $LASTEXITCODE

if ($robocopyExit -ge 8) {
    throw "robocopy site staging failed with exit code $robocopyExit."
}

Write-Host "Tracked website output: $TrackedSiteRoot"

if (-not $SkipGit) {
    Write-Step "Backing up vault with Git"

    & git -C $VaultPath add -A
    if ($LASTEXITCODE -ne 0) {
        throw "git add failed."
    }

    $changes = & git -C $VaultPath status --porcelain

    if ($changes) {
        $commitMessage = "Publish Shag's Lab $(Get-Date -Format 'yyyy-MM-dd HH:mm')"
        & git -C $VaultPath commit -m $commitMessage
        if ($LASTEXITCODE -ne 0) {
            throw "git commit failed."
        }
    }
    else {
        Write-Host "Vault working tree is already clean."
    }

    $remotes = @(& git -C $VaultPath remote)
    if ($remotes -contains "origin") {
        & git -C $VaultPath push origin main
        if ($LASTEXITCODE -ne 0) {
            throw "git push failed."
        }
        Write-Host "Pushed vault backup to origin/main."
    }
    else {
        Write-Warning "No Git remote named 'origin' exists yet. Local Git backup is complete, but nothing was pushed off-machine."
    }
}

Write-Step "Done"
Write-Host "Quartz build output: $PublicRoot"
Write-Host "Tracked site output: $TrackedSiteRoot"
Write-Host ""
Write-Host "On the web host, run Update-ShagsLab-WebHost.bat."
```

## `Update-ShagsLab-WebHost.bat`

Save this somewhere convenient on the web host.

It pulls the private repository and mirrors only the generated site into Apache's public folder.

```bat
@echo off
setlocal

rem === Shag's Lab website updater - WEB HOST ===
rem Pulls the latest repo from GitHub, then mirrors the generated site
rem into Apache's live web root.

set "REPO_DIR=C:\PGN\ShagsLab"
set "WEB_DIR=C:\xampp\htdocs\helvete\lab"
set "SITE_DIR=%REPO_DIR%\.site\public"

echo.
echo ========================================
echo   Updating Shag's Lab
echo ========================================
echo.

echo Checking Git...
where git >nul 2>&1
if errorlevel 1 (
    echo ERROR: Git is not installed or is not in PATH on this machine.
    echo.
    pause
    exit /b 1
)

git --version
echo.

if not exist "%REPO_DIR%\.git" (
    echo ERROR: Git repository not found:
    echo   %REPO_DIR%
    echo.
    echo The repo must be cloned to that folder first.
    echo.
    echo Example:
    echo   git clone YOUR_GITHUB_REPO_URL "%REPO_DIR%"
    echo.
    pause
    exit /b 1
)

cd /d "%REPO_DIR%"

echo Repository found.
echo.
echo Current remotes:
git remote -v
echo.

echo Pulling latest version from origin/main...
git pull --ff-only origin main

if errorlevel 1 (
    echo.
    echo ERROR: Git pull failed.
    echo Common causes:
    echo   - GitHub authentication is not set up on this PC
    echo   - origin is missing or points to the wrong repo
    echo   - the branch is not named main
    echo.
    pause
    exit /b 1
)

if not exist "%SITE_DIR%\index.html" (
    echo.
    echo ERROR: Generated site was not found:
    echo   %SITE_DIR%
    echo.
    echo Run Publish-ShagsLab-HomePC.bat on the home PC first,
    echo make sure it pushes successfully, then run this updater again.
    echo.
    pause
    exit /b 1
)

if not exist "%WEB_DIR%" (
    echo Creating live web folder:
    echo   %WEB_DIR%
    mkdir "%WEB_DIR%"
)

echo.
echo Publishing generated site to Apache...
robocopy "%SITE_DIR%" "%WEB_DIR%" /MIR /R:2 /W:1 /NFL /NDL /NP

if errorlevel 8 (
    echo.
    echo ERROR: Website copy failed.
    echo.
    pause
    exit /b 1
)

echo.
echo ========================================
echo   Shag's Lab is up to date
echo ========================================
echo.
echo Repository:
echo   %REPO_DIR%
echo.
echo Live website:
echo   %WEB_DIR%
echo.
pause

exit /b 0
```
