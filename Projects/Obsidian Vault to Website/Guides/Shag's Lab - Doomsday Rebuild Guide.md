# Shag's Lab: The Doomsday Rebuild Guide

This is the file for Future Me, Curious You, or Whoever Is Looking At A Dead PC Wondering Why A Personal Wiki Needed A Build Pipeline.

The short version:

**The Obsidian vault is the source of truth.**

Everything else is replaceable.

The live site is a static Quartz build made from explicitly public notes in that vault. The vault and generated site live in one private Git repository. The home PC builds and pushes it. The web host pulls it and copies only the finished public files into Apache's web root.

If every piece of software involved in this project vanished tomorrow, the important part would still be a folder full of Markdown files and images.

That is the point.

## The content model

Do not overcomplicate this.

There are two main things:

- **Updates** are chronological diary entries.
- **Projects** are persistent wiki-ish things.

An Update should normally have:

```yaml
---
type: update
date: 2026-09-19
project: Exact Project Name
publish: true
---
```

A Project Home should normally have:

```yaml
---
type: project
project: Exact Project Name
status: active
publish: true
---
```

The `project:` value on the Project Home and its Updates should match.

That is how the publisher knows which Updates belong to which Project and can sort Projects by recent activity.

The homepage should contain:

```yaml
---
title: Welcome
publish: true
---
```

`Updates/Updates Home.md` and `Projects/Projects Home.md` are generated by the publisher.

**Do not lovingly hand-maintain those lists. The script will overwrite them.**

Anything without:

```yaml
publish: true
```

stays out of the public build.

## Normal publishing workflow

On the home PC:

1. Work normally in Obsidian.
2. Add/update notes.
3. Set `publish: true` only on things that should be public.
4. Run `Publish-ShagsLab-HomePC.bat`.

That BAT runs the PowerShell publisher.

The publisher:

1. Scans the vault.
2. Generates `Updates Home`.
3. Generates `Projects Home`.
4. Creates a clean Quartz staging directory.
5. Copies only published notes.
6. Copies assets referenced by published notes.
7. Turns `Welcome.md` into `index.md`.
8. Builds Quartz.
9. Mirrors the built static site into `.site\public` inside the vault repository.
10. Commits the vault and generated site.
11. Pushes `main` to GitHub.

Then, on the web host, run:

```text
Update-ShagsLab-WebHost.bat
```

That:

1. Pulls `origin/main`.
2. Verifies `.site\public\index.html` exists.
3. Mirrors `.site\public` into `C:\xampp\htdocs\helvete\lab`.

Done.


Clone the private repo:

```powershell

Set-Location -LiteralPath "F:\[DIARY]\Shag's Lab"
```


Restore `Publish-Lab.ps1` from the copy embedded later in this guide.

The web-host BAT uses:


## Metadata troubleshooting

If an Update does not appear on `Updates Home`, verify:

```yaml
type: update
date: YYYY-MM-DD
publish: true
```

If a Project does not sort based on its newest Update, verify the Project Home and Update use exactly the same `project:` value.

Example:

Project Home:

```yaml
project: Keychron C100
```

Update:

```yaml
project: Keychron C100
```

If they differ, the generator treats them as different projects.

If a note appears in Obsidian but not publicly, verify it has:

```yaml
publish: true
```

That omission is a feature, not a bug.

## Quartz troubleshooting

### Homepage is a 404

Quartz expects:

```text
content\index.md
```

The publisher creates it from `Welcome.md`.

Verify `Welcome.md` contains:

```yaml
---
title: Welcome
publish: true
---
```

Then rerun the publisher.

### Homepage is titled `index`

Same issue: make sure the `title: Welcome` frontmatter is present before building.

### Explorer is empty and Graph View is one dot

Quartz has only received one note, usually because `content` was manually populated incorrectly.

Do not manually maintain `ShagsLab-Web\content`.

Run the publisher so it regenerates the staging directory from the vault.

### `@quartz-themes/default` cannot be found

From:

```text
F:\[DIARY]\ShagsLab-Web
```

run:

```powershell
npm install @quartz-themes/default
```

then rebuild.

### Windows PowerShell throws bizarre parse errors around normal code

The publisher must remain safe for Windows PowerShell 5.1.

The original failure came from a Unicode em dash in a UTF-8-without-BOM `.ps1`, which PowerShell misread and then produced a cascade of nonsense parser errors.

Keep the operational publisher script ASCII-only unless PowerShell encoding behavior is deliberately changed.

## The actual backup philosophy

There are several layers here and they have different jobs:

```text
Obsidian vault
    = original source

Local Git
    = local history

Private GitHub
    = off-machine copy + transport

.site\public
    = generated website snapshot

Web host checkout
    = deploy source

Apache lab folder
    = disposable live copy
```

The most important data is always:

```text
F:\[DIARY]\Shag's Lab
```

If the website disappears, rebuild it.

If Apache disappears, rebuild it.

If Quartz disappears, replace it with something else.

Do not contort the vault around the website.

The website exists to present the vault.

The vault does not exist to feed the website.

## `Publish-Lab.ps1`

Save as:

```text
F:\[DIARY]\ShagsLab-Web\Publish-Lab.ps1
```

```powershell
param(
    [string]$VaultPath = "F:\[DIARY]\Shag's Lab",
    [string]$QuartzRoot = "F:\[DIARY]\ShagsLab-Web",
    [string]$TrackedSiteRoot = "F:\[DIARY]\Shag's Lab\.site\public",
    [switch]$Serve,
    [switch]$SkipGit
)

$ErrorActionPreference = "Stop"

function Write-Step {
    param([string]$Message)
    Write-Host ""
    Write-Host "==> $Message" -ForegroundColor Cyan
}

function Write-Utf8NoBom {
    param(
        [string]$Path,
        [string]$Text
    )
    $parent = Split-Path -Parent $Path
    if ($parent -and -not (Test-Path -LiteralPath $parent)) {
        New-Item -ItemType Directory -Path $parent -Force | Out-Null
    }
    $utf8 = New-Object System.Text.UTF8Encoding($false)
    [System.IO.File]::WriteAllText($Path, $Text, $utf8)
}

function Get-RelativePathFromRoot {
    param(
        [string]$Root,
        [string]$FullPath
    )
    $rootNormalized = $Root.TrimEnd('\')
    if (-not $FullPath.StartsWith($rootNormalized, [System.StringComparison]::OrdinalIgnoreCase)) {
        throw "Path '$FullPath' is not inside '$Root'."
    }
    return $FullPath.Substring($rootNormalized.Length).TrimStart('\')
}

function Get-FrontMatter {
    param([string]$Text)

    $result = @{}
    $normalized = $Text -replace "`r`n", "`n"

    if (-not $normalized.StartsWith("---`n")) {
        return $result
    }

    $end = $normalized.IndexOf("`n---`n", 4)
    if ($end -lt 0) {
        return $result
    }

    $block = $normalized.Substring(4, $end - 4)

    foreach ($line in ($block -split "`n")) {
        if ($line -match '^\s*([A-Za-z0-9_-]+)\s*:\s*(.*?)\s*$') {
            $key = $Matches[1].ToLowerInvariant()
            $value = $Matches[2].Trim()

            if (($value.StartsWith('"') -and $value.EndsWith('"')) -or
                ($value.StartsWith("'") -and $value.EndsWith("'"))) {
                $value = $value.Substring(1, $value.Length - 2)
            }

            $result[$key] = $value
        }
    }

    return $result
}

function Convert-ToDate {
    param([string]$Value)

    if ([string]::IsNullOrWhiteSpace($Value)) {
        return [datetime]::MinValue
    }

    try {
        return [datetime]::Parse($Value, [System.Globalization.CultureInfo]::InvariantCulture)
    }
    catch {
        return [datetime]::MinValue
    }
}

function Get-ProjectKeysFromUpdate {
    param([string]$ProjectValue)

    if ([string]::IsNullOrWhiteSpace($ProjectValue)) {
        return @()
    }

    # Supports the current simple format:
    # project: Keychron C100
    # project: BASS VI - Penny, GitHub
    return @(
        $ProjectValue -split ',' |
        ForEach-Object { $_.Trim() } |
        Where-Object { $_ }
    )
}

function Get-WikiTarget {
    param([string]$RawTarget)

    $target = $RawTarget.Trim()

    if ($target.Contains('|')) {
        $target = $target.Split('|')[0]
    }
    if ($target.Contains('#')) {
        $target = $target.Split('#')[0]
    }

    return $target.Trim()
}

if (-not (Test-Path -LiteralPath $VaultPath -PathType Container)) {
    throw "Vault not found: $VaultPath"
}
if (-not (Test-Path -LiteralPath $QuartzRoot -PathType Container)) {
    throw "Quartz root not found: $QuartzRoot"
}

$ContentRoot = Join-Path $QuartzRoot "content"
$PublicRoot = Join-Path $QuartzRoot "public"

Write-Step "Scanning Shag's Lab"

$noteFiles = Get-ChildItem -LiteralPath $VaultPath -Recurse -File -Filter "*.md" |
    Where-Object {
        $_.FullName -notmatch '\\\.git\\' -and
        $_.FullName -notmatch '\\\.obsidian\\' -and
        $_.FullName -notmatch '\\\.trash\\'
    }

$notes = foreach ($file in $noteFiles) {
    $text = Get-Content -LiteralPath $file.FullName -Raw
    $fm = Get-FrontMatter -Text $text

    $publish = $false
    if ($fm.ContainsKey("publish")) {
        $publish = $fm["publish"].ToLowerInvariant() -eq "true"
    }

    $draft = $false
    if ($fm.ContainsKey("draft")) {
        $draft = $fm["draft"].ToLowerInvariant() -eq "true"
    }

    $type = if ($fm.ContainsKey("type")) { $fm["type"].ToLowerInvariant() } else { "" }
    $title = if ($fm.ContainsKey("title")) { $fm["title"] } else { $file.BaseName }
    $dateRaw = if ($fm.ContainsKey("date")) { $fm["date"] } else { "" }
    $project = if ($fm.ContainsKey("project")) { $fm["project"] } else { "" }
    $status = if ($fm.ContainsKey("status")) { $fm["status"] } else { "" }

    [pscustomobject]@{
        Source       = $file.FullName
        Relative     = Get-RelativePathFromRoot -Root $VaultPath -FullPath $file.FullName
        Directory    = $file.DirectoryName
        Name         = $file.BaseName
        Text         = $text
        FrontMatter  = $fm
        Publish      = ($publish -and -not $draft)
        Type         = $type
        Title        = $title
        DateRaw      = $dateRaw
        DateValue    = Convert-ToDate -Value $dateRaw
        Project      = $project
        Status       = $status
        Modified     = $file.LastWriteTime
    }
}

$publicUpdates = @(
    $notes |
    Where-Object { $_.Publish -and $_.Type -eq "update" } |
    Sort-Object @{ Expression = { $_.DateValue }; Descending = $true },
                @{ Expression = { $_.Name }; Descending = $true }
)

$publicProjects = @(
    $notes |
    Where-Object { $_.Publish -and $_.Type -eq "project" }
)

Write-Step "Generating Updates Home"

$updatesLines = New-Object System.Collections.Generic.List[string]
$updatesLines.Add("---")
$updatesLines.Add("title: Updates Home")
$updatesLines.Add("type: index")
$updatesLines.Add("publish: true")
$updatesLines.Add("---")
$updatesLines.Add("")
$updatesLines.Add("*This page is auto-generated.*")
$updatesLines.Add("")
$updatesLines.Add("## Latest Updates")
$updatesLines.Add("")

foreach ($update in $publicUpdates) {
    $target = ($update.Relative -replace '\\', '/') -replace '\.md$', ''
    $updatesLines.Add("- [[$target|$($update.Name)]]")
}

if ($publicUpdates.Count -eq 0) {
    $updatesLines.Add("_No published updates yet._")
}

if ($publicUpdates.Count -gt 0) {
    $updatesLines.Add("")
    $updatesLines.Add("*Last Updated: $($publicUpdates[0].DateValue.ToString('yyyy-MM-dd'))*")
}

$updatesHomePath = Join-Path $VaultPath "Updates\Updates Home.md"
Write-Utf8NoBom -Path $updatesHomePath -Text (($updatesLines -join "`r`n") + "`r`n")

Write-Step "Generating Projects Home"

$projectRows = foreach ($projectNote in $publicProjects) {
    $displayName = $projectNote.Title
    if ($displayName -eq $projectNote.Name) {
        $displayName = $displayName -replace '\s+Home$', ''
    }

    $projectKey = if (-not [string]::IsNullOrWhiteSpace($projectNote.Project)) {
        $projectNote.Project
    }
    else {
        $displayName
    }

    $matchingUpdates = @(
        $publicUpdates | Where-Object {
            $keys = Get-ProjectKeysFromUpdate -ProjectValue $_.Project
            $keys | Where-Object { $_ -ieq $projectKey }
        }
    )

    if ($matchingUpdates.Count -gt 0) {
        $activityDate = ($matchingUpdates | Sort-Object DateValue -Descending | Select-Object -First 1).DateValue
    }
    else {
        $activityDate = $projectNote.Modified
        Write-Warning "No published update matched project '$projectKey'. Using the project note's modified date. Add 'project: $projectKey' to the project Home note and use the same value on its update posts for exact sorting."
    }

    [pscustomobject]@{
        Note         = $projectNote
        DisplayName  = $displayName
        ProjectKey   = $projectKey
        ActivityDate = $activityDate
    }
}

$projectRows = @(
    $projectRows |
    Sort-Object @{ Expression = { $_.ActivityDate }; Descending = $true },
                @{ Expression = { $_.DisplayName }; Descending = $false }
)

$projectsLines = New-Object System.Collections.Generic.List[string]
$projectsLines.Add("---")
$projectsLines.Add("title: Projects Home")
$projectsLines.Add("type: index")
$projectsLines.Add("publish: true")
$projectsLines.Add("---")
$projectsLines.Add("")
$projectsLines.Add("*This page is auto-generated.*")
$projectsLines.Add("")
$projectsLines.Add("## Projects")
$projectsLines.Add("")

foreach ($row in $projectRows) {
    $target = ($row.Note.Relative -replace '\\', '/') -replace '\.md$', ''
    $dateText = $row.ActivityDate.ToString("yyyy-MM-dd")
    $projectsLines.Add("- [[$target|$($row.DisplayName)]] - last activity $dateText")
}

if ($projectRows.Count -eq 0) {
    $projectsLines.Add("_No published projects yet._")
}

if ($projectRows.Count -gt 0) {
    $projectsLines.Add("")
    $projectsLines.Add("*Last Updated: $($projectRows[0].ActivityDate.ToString('yyyy-MM-dd'))*")
}

$projectsHomePath = Join-Path $VaultPath "Projects\Projects Home.md"
Write-Utf8NoBom -Path $projectsHomePath -Text (($projectsLines -join "`r`n") + "`r`n")

# Re-scan so the freshly generated Home pages are included.
$noteFiles = Get-ChildItem -LiteralPath $VaultPath -Recurse -File -Filter "*.md" |
    Where-Object {
        $_.FullName -notmatch '\\\.git\\' -and
        $_.FullName -notmatch '\\\.obsidian\\' -and
        $_.FullName -notmatch '\\\.trash\\'
    }

$notes = foreach ($file in $noteFiles) {
    $text = Get-Content -LiteralPath $file.FullName -Raw
    $fm = Get-FrontMatter -Text $text

    $publish = $false
    if ($fm.ContainsKey("publish")) {
        $publish = $fm["publish"].ToLowerInvariant() -eq "true"
    }

    $draft = $false
    if ($fm.ContainsKey("draft")) {
        $draft = $fm["draft"].ToLowerInvariant() -eq "true"
    }

    [pscustomobject]@{
        Source      = $file.FullName
        Relative    = Get-RelativePathFromRoot -Root $VaultPath -FullPath $file.FullName
        Directory   = $file.DirectoryName
        Name        = $file.BaseName
        Text        = $text
        Publish     = ($publish -and -not $draft)
    }
}

Write-Step "Creating clean public staging copy"

if (Test-Path -LiteralPath $ContentRoot) {
    Remove-Item -LiteralPath $ContentRoot -Recurse -Force
}
New-Item -ItemType Directory -Path $ContentRoot -Force | Out-Null

$publishedNotes = @($notes | Where-Object { $_.Publish })

$welcome = $publishedNotes | Where-Object { $_.Relative -ieq "Welcome.md" } | Select-Object -First 1
if (-not $welcome) {
    throw "Welcome.md must contain 'publish: true'. It becomes the public site's index.md."
}

foreach ($note in $publishedNotes) {
    if ($note.Relative -ieq "Welcome.md") {
        $destination = Join-Path $ContentRoot "index.md"
    }
    else {
        $destination = Join-Path $ContentRoot $note.Relative
    }

    $parent = Split-Path -Parent $destination
    if (-not (Test-Path -LiteralPath $parent)) {
        New-Item -ItemType Directory -Path $parent -Force | Out-Null
    }

    Copy-Item -LiteralPath $note.Source -Destination $destination -Force
}

# Build an index of non-Markdown files so only attachments actually referenced

$assetFiles = Get-ChildItem -LiteralPath $VaultPath -Recurse -File |
    Where-Object {
        $_.Extension -ine ".md" -and
        $_.FullName -notmatch '\\\.git\\' -and
        $_.FullName -notmatch '\\\.obsidian\\' -and
        $_.FullName -notmatch '\\\.trash\\'
    }

$assetsByName = @{}
foreach ($asset in $assetFiles) {
    $key = $asset.Name.ToLowerInvariant()
    if (-not $assetsByName.ContainsKey($key)) {
        $assetsByName[$key] = New-Object System.Collections.ArrayList
    }
    [void]$assetsByName[$key].Add($asset)
}

function Resolve-Attachment {
    param(
        [string]$Target,
        [string]$NoteDirectory
    )

    $clean = Get-WikiTarget -RawTarget $Target
    if ([string]::IsNullOrWhiteSpace($clean)) {
        return $null
    }

    if ($clean -match '^[a-zA-Z][a-zA-Z0-9+.-]*://') {
        return $null
    }

    $cleanFs = $clean -replace '/', '\'

    $sameFolder = Join-Path $NoteDirectory $cleanFs
    if (Test-Path -LiteralPath $sameFolder -PathType Leaf) {
        $item = Get-Item -LiteralPath $sameFolder
        if ($item.Extension -ine ".md") {
            return $item
        }
    }

    $fromRoot = Join-Path $VaultPath $cleanFs
    if (Test-Path -LiteralPath $fromRoot -PathType Leaf) {
        $item = Get-Item -LiteralPath $fromRoot
        if ($item.Extension -ine ".md") {
            return $item
        }
    }

    $leaf = Split-Path -Leaf $cleanFs
    if ($assetsByName.ContainsKey($leaf.ToLowerInvariant())) {
        $matches = @($assetsByName[$leaf.ToLowerInvariant()])
        if ($matches.Count -gt 1) {
            Write-Warning "Attachment '$clean' is ambiguous; using '$($matches[0].FullName)'."
        }
        return $matches[0]
    }

    return $null
}

$copiedAssets = @{}

foreach ($note in $publishedNotes) {
    $targets = New-Object System.Collections.Generic.List[string]

    foreach ($match in [regex]::Matches($note.Text, '\[\[([^\]]+)\]\]')) {
        $targets.Add($match.Groups[1].Value)
    }

    foreach ($match in [regex]::Matches($note.Text, '!?\[[^\]]*\]\(([^)]+)\)')) {
        $targets.Add($match.Groups[1].Value)
    }

    foreach ($target in $targets) {
        $asset = Resolve-Attachment -Target $target -NoteDirectory $note.Directory
        if (-not $asset) {
            continue
        }

        if ($copiedAssets.ContainsKey($asset.FullName)) {
            continue
        }

        $relativeAsset = Get-RelativePathFromRoot -Root $VaultPath -FullPath $asset.FullName
        $assetDestination = Join-Path $ContentRoot $relativeAsset
        $assetParent = Split-Path -Parent $assetDestination

        if (-not (Test-Path -LiteralPath $assetParent)) {
            New-Item -ItemType Directory -Path $assetParent -Force | Out-Null
        }

        Copy-Item -LiteralPath $asset.FullName -Destination $assetDestination -Force
        $copiedAssets[$asset.FullName] = $true
    }
}

Write-Host "Published notes: $($publishedNotes.Count)"
Write-Host "Referenced attachments copied: $($copiedAssets.Count)"

Write-Step "Building Quartz"

Push-Location -LiteralPath $QuartzRoot
try {
    if ($Serve) {
        Write-Host "Starting local preview at http://localhost:8080/"
        Write-Host "Press Ctrl+C when you're finished."
        & npx quartz build --serve
        exit $LASTEXITCODE
    }

    & npx quartz build
    if ($LASTEXITCODE -ne 0) {
        throw "Quartz build failed with exit code $LASTEXITCODE."
    }
}
finally {
    Pop-Location
}

Write-Step "Copying built website into the same Git repo"

$trackedParent = Split-Path -Parent $TrackedSiteRoot
if (-not (Test-Path -LiteralPath $trackedParent)) {
    New-Item -ItemType Directory -Path $trackedParent -Force | Out-Null
}

if (-not (Test-Path -LiteralPath $TrackedSiteRoot)) {
    New-Item -ItemType Directory -Path $TrackedSiteRoot -Force | Out-Null
}

& robocopy $PublicRoot $TrackedSiteRoot /MIR /R:2 /W:1 /NFL /NDL /NP
$robocopyExit = $LASTEXITCODE

if ($robocopyExit -ge 8) {
    throw "robocopy site staging failed with exit code $robocopyExit."
}

Write-Host "Tracked website output: $TrackedSiteRoot"

if (-not $SkipGit) {
    Write-Step "Backing up vault with Git"

    & git -C $VaultPath add -A
    if ($LASTEXITCODE -ne 0) {
        throw "git add failed."
    }

    $changes = & git -C $VaultPath status --porcelain

    if ($changes) {
        $commitMessage = "Publish Shag's Lab $(Get-Date -Format 'yyyy-MM-dd HH:mm')"
        & git -C $VaultPath commit -m $commitMessage
        if ($LASTEXITCODE -ne 0) {
            throw "git commit failed."
        }
    }
    else {
        Write-Host "Vault working tree is already clean."
    }

    $remotes = @(& git -C $VaultPath remote)
    if ($remotes -contains "origin") {
        & git -C $VaultPath push origin main
        if ($LASTEXITCODE -ne 0) {
            throw "git push failed."
        }
        Write-Host "Pushed vault backup to origin/main."
    }
    else {
        Write-Warning "No Git remote named 'origin' exists yet. Local Git backup is complete, but nothing was pushed off-machine."
    }
}

Write-Step "Done"
Write-Host "Quartz build output: $PublicRoot"
Write-Host "Tracked site output: $TrackedSiteRoot"
Write-Host ""
Write-Host "On the web host, run Update-ShagsLab-WebHost.bat."
```

## `Update-ShagsLab-WebHost.bat`

Save this somewhere convenient on the web host.

It pulls the private repository and mirrors only the generated site into Apache's public folder.

```bat
@echo off
setlocal

rem === Shag's Lab website updater - WEB HOST ===
rem Pulls the latest repo from GitHub, then mirrors the generated site
rem into Apache's live web root.

set "REPO_DIR=C:\PGN\ShagsLab"
set "WEB_DIR=C:\xampp\htdocs\helvete\lab"
set "SITE_DIR=%REPO_DIR%\.site\public"

echo.
echo ========================================
echo   Updating Shag's Lab
echo ========================================
echo.

echo Checking Git...
where git >nul 2>&1
if errorlevel 1 (
    echo ERROR: Git is not installed or is not in PATH on this machine.
    echo.
    pause
    exit /b 1
)

git --version
echo.

if not exist "%REPO_DIR%\.git" (
    echo ERROR: Git repository not found:
    echo   %REPO_DIR%
    echo.
    echo The repo must be cloned to that folder first.
    echo.
    echo Example:
    echo   git clone YOUR_GITHUB_REPO_URL "%REPO_DIR%"
    echo.
    pause
    exit /b 1
)

cd /d "%REPO_DIR%"

echo Repository found.
echo.
echo Current remotes:
git remote -v
echo.

echo Pulling latest version from origin/main...
git pull --ff-only origin main

if errorlevel 1 (
    echo.
    echo ERROR: Git pull failed.
    echo Common causes:
    echo   - GitHub authentication is not set up on this PC
    echo   - origin is missing or points to the wrong repo
    echo   - the branch is not named main
    echo.
    pause
    exit /b 1
)

if not exist "%SITE_DIR%\index.html" (
    echo.
    echo ERROR: Generated site was not found:
    echo   %SITE_DIR%
    echo.
    echo Run Publish-ShagsLab-HomePC.bat on the home PC first,
    echo make sure it pushes successfully, then run this updater again.
    echo.
    pause
    exit /b 1
)

if not exist "%WEB_DIR%" (
    echo Creating live web folder:
    echo   %WEB_DIR%
    mkdir "%WEB_DIR%"
)

echo.
echo Publishing generated site to Apache...
robocopy "%SITE_DIR%" "%WEB_DIR%" /MIR /R:2 /W:1 /NFL /NDL /NP

if errorlevel 8 (
    echo.
    echo ERROR: Website copy failed.
    echo.
    pause
    exit /b 1
)

echo.
echo ========================================
echo   Shag's Lab is up to date
echo ========================================
echo.
echo Repository:
echo   %REPO_DIR%
echo.
echo Live website:
echo   %WEB_DIR%
echo.
pause

exit /b 0
```
