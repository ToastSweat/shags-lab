## About
A small Windows downloader that checks Rule34.xxx for selected **Copyright**, **Character**, **Artist**, and **General** tags. It uses the site's JSON API, keeps resumable SQLite history, and has no third-party Python dependencies.
[GitHub](https://github.com/ToastSweat/r34-tag-watcher)

If you want to do this yourself, I have prepared a guide.
[[Rule34 Tag Watcher - How Do]]

The doomsday rebuild guide has some useful information too, especially if you are running into issues or are coming back to this years later like I probably will.
[[Rule34 Tag Watcher - Doomsday Rebuild Guide]]
