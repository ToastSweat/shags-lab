# Garth's Game DMG

Garth's Game I is an actual Game Boy virtual-pet game built in C with GBDK 2020.

Garth has persistent needs, moods, minigames, dialogue, a synthesized voice, music, sound effects, SRAM saving, and progression. The current playable build has three care stats and three minigames. The next version is a major visual/gameplay redesign with a new home screen, a fourth GAS stat, four named minigames, jokes, and mood-driven animation.

The ultimate goal is not only a ROM.

I want a cartridge, label, box, and manual.

## Current state

### Working foundation

- FOOD, FUN, and POWER stats
- Time-based decay and moods
- FEED, PLAY, and NAP minigames
- TALK/HANGOUT dialogue
- Lang808 synthesized speech
- Menu, mood, minigame, and result music
- Sound effects
- SRAM save/load
- Stat-cap progression from 30 toward 100
- Four randomized menu backgrounds

### Redesign in progress

- New cabin home screen
- Animated Garth based on mood
- FOOD, FUN, POWER, and inverse-pressure GAS
- Four consistent title/game/results minigames
- Joke action and refined TALK mode
- New music and sound effects
- Final Game Boy tile/bank optimization
