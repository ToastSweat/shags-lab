# ChatGPT

**ChatGPT** is OpenAI's conversational AI product. You can ask it to explain something, help draft text, or work through a programming problem. It produces useful suggestions, but a confident answer still isn't proof that a command, fact, or piece of code is correct.

In [[2026-09-16 - I Made A Custom Driver|the keyboard firmware update]], ChatGPT helped point the investigation toward [[Wiki/QMK|QMK]] and Keychron's [[Wiki/open-source|open-source]] firmware. That gave the project somewhere concrete to go: source code, a compiler, and eventually a working key that typed a symbol.

It isn't the same thing as [[Wiki/Hermes Agent|Hermes Agent]]. Hermes is a separate agent system that can connect models to tools and workflows. With either product, the useful habit is the same: verify important claims against documentation and test the actual result.
