# ANAL RPG

ANAL RPG is the name of an MTA server project described in Shagwrath's personal [[Wiki/Multi Theft Auto|Multi Theft Auto]] history. He says people from the earlier server branches got back together during COVID to make it, adding that the name was not his finest choice but that he was proud of the work.

That is the extent of the current direct account. The note places the reunion after [[Wiki/Why So Serious RPG|Why So Serious RPG]], [[Wiki/Progeny Gaming Network|Progeny Gaming Network]], and the Nightlife/Excision branches, but does not provide an exact year, launch record, feature list, or expansion of the initials.

The name is retained here because it is an actual local history target, not because this page can reconstruct the whole server from a passing mention. More authored recollection or older project records would be needed to explain what was built and how the reunion ended.
