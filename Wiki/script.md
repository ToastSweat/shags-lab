# Script

A **script** is a file of instructions that another program runs. Instead of typing the same commands every time, you save them and let the computer follow the sequence. Scripts can also make decisions, handle errors, and work through lists of files or requests.

The [[Booru Image Downloader Home|image downloader]] uses [[Wiki/Python|Python]] for its main work and [[Wiki/PowerShell|PowerShell]] around Windows setup. The [[Obsidian Vault to Website Home|website workflow]] uses scripts to turn notes into a publishable site.

The file needs the right interpreter: a PowerShell script isn't a batch file, and neither is a Python program. [[Wiki/Command Prompt|Command Prompt]] won't magically understand every command pasted into it.

Scripts can delete files, change settings, or send information elsewhere. Read unfamiliar ones before running them, keep [[Wiki/credentials|credentials]] out of shared copies, and test risky work against a safe target first.
