# HK-47

HK-47 is the assassin droid from *Star Wars: Knights of the Old Republic*, known for dry delivery and referring to organic beings as “meatbags.” In this vault, the name also belongs to the custom bot/bridge attached to PGN's [[Wiki/Star Wars Battlefront II|Star Wars Battlefront II]] server. The fictional character and the local software are not the same thing.

The local HK-47 handles chat, announces battles, and, in the October 6, 2026 update, gains automatic PvE team assignment. It checks the game's current players through SWBF2Admin and moves humans to the configured faction. The server's Auto Assign setting prevents normal team selection from immediately undoing that work.

That post reports the v1.3.0 implementation and live test, with humans assigned to Republic clones in Clone Wars and the Empire in Galactic Civil War. It is a dated project milestone, not a claim that this page has checked the live server today.

See [[2026-10-06 - I Made HK-47 Assign The Teams]] for the detailed account and [[Star Wars Battlefront II Dedicated Server Home]] for the roadmap, including features that are still only planned.
