# Hermes Agent

**Hermes Agent** is an [[Wiki/open-source|open-source]] AI agent built by Nous Research. Rather than only replying in chat, it can use tools to work with files, run commands, and carry out tasks. It can connect to different model providers instead of being tied to one model.

Its reusable *skills* store procedures for later work, and its memory features help carry useful context across sessions. Those are conveniences, not guarantees that every decision is correct.

In [[2026-10-17 - I Wanted a Chatbot. Hermes Built Me a Platform|the chatbot project]], Hermes helped build the application in tested increments. The valuable part wasn't just generating code: it was checking the behavior and keeping [[Wiki/backups|backups]] before risky changes.

Hermes and [[Wiki/ChatGPT|ChatGPT]] are different products. For setup and feature details, use the [official Hermes documentation](https://hermes-agent.nousresearch.com/docs/) rather than treating an old project note as installation instructions.
