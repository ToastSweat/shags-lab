# Dedicated Servers

A **dedicated server** runs the hosting side of a game separately from the players' game clients. It can keep a shared world or match available without depending on one player staying connected as the host.

“Dedicated” describes the server's role; it doesn't always mean the entire physical computer runs only that one game. A machine can host several separate services if its resources and configuration allow it.

The [[Star Wars Battlefront II Dedicated Server Home|Battlefront II project]] and [[Dune Awakening Private Server Home|Dune project]] are local examples. Their needs differ, but both involve configuration, remote access, persistence, and [[Wiki/backups|backups]], not just starting an executable once.

A healthy process isn't the final test. Players need to be able to connect, saved data needs to survive, and administration shouldn't interrupt the game. That's why the Battlefront notes distinguish its game session from ordinary [[Wiki/Remote Desktop Connection|Remote Desktop Connection]] access.
