# Markdown

**Markdown** is a plain-text way to write formatted documents. A few visible marks represent headings, emphasis, lists, links, and code blocks. You can read the source in an ordinary text editor without needing the original app.

Most notes in this vault are Markdown files. [[Wiki/Obsidian|Obsidian]] adds convenient features such as `[[wikilinks]]` and embedded attachments, while [[Wiki/Quartz|Quartz]] turns the selected notes into website pages. Not every Markdown reader understands every Obsidian extension.

The block between `---` lines at the start of a note is *frontmatter*: structured metadata rather than the article itself. Here, fields such as `type: wiki` and `publish: true` tell the publishing workflow how to handle a note.

Plain text is portable, but a document can still depend on linked images and other notes. Useful [[Wiki/backups|backups]] preserve those connections as well as the words.
