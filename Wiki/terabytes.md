# Terabytes

A **terabyte**, abbreviated **TB**, is a large unit used to describe storage capacity. It means a trillion [[Wiki/bytes|bytes]]. A related unit, the tebibyte or TiB, uses a binary scale instead, which helps explain why storage totals can look different across labels and software.

In [[2026-09-17 - I Built A Booru Librarian|the image downloader update]], storage became a problem because the same image could be copied into several matching tag folders. Enough duplicates turn “it's only one more folder” into a very expensive habit.

[[Wiki/hard links|hard links]] address that particular waste by giving one stored file several names. They don't shrink the image itself, and folder-size tools can still count its apparent size repeatedly.

For that archive, actual used and free space on the [[Wiki/NTFS volume|NTFS volume]] tells a different story from simply adding every visible folder's reported size.
