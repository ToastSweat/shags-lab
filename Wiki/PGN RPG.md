# PGN RPG

PGN RPG is the [[Wiki/Multi Theft Auto|Multi Theft Auto]] server named in the author's account of forming [[Wiki/Progeny Gaming Network|Progeny Gaming Network]]. In that history, Shagwrath and friends leave [[Wiki/Why So Serious RPG|Why So Serious RPG]] and start both the community and its own RPG server.

The server and the community should not be treated as interchangeable. PGN grew into a long-running friend group with many games, servers, and software projects; PGN RPG is one particular part of its earlier MTA story.

The existing personal note establishes the connection, but not a launch date, complete feature list, staff roster, or shutdown date. The community home dates PGN's formation to around 2015, which is useful context rather than proof of the server's exact opening day.

Later branches in the same account include Nightlife, Excision, and a reunion during COVID to make [[Wiki/ANAL RPG|ANAL RPG]]. For the broader history, start at [[Progeny Gaming Network Home]] or [[PGN - Game Eras and Server Genealogy]]. Older records would be needed to turn this short entry into a detailed server history.
