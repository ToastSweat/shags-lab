# Dune Awakening

Dune: Awakening is a survival game set in the Dune universe, with Arrakis providing the sand, danger, and reason to think carefully about water. In this vault, the main story is not a general game review: it is getting a small group's private server working and keeping that effort recoverable.

[[Dune Awakening Private Server Home]] explains the motivation plainly. Paying a recurring rental fee made less sense when only a couple of friends were actively playing, so the author and a friend worked on a private setup and settings suited to two players.

The September and October 2026 updates follow the practical consequences: server settings, backups, and documentation so the next rebuild does not require rediscovering every painful detail. The project home is marked paused; that status should not be mistaken for proof that a particular server is currently online or offline.

Start with [[Dune Private Server Settings Reference]] for the documented settings and [[Dune Private Server Doomsday Guide]] for recovery. Related: [[Wiki/Progeny Gaming Network|Progeny Gaming Network]], [[Wiki/Valheim|Valheim]], and [[Wiki/Video Games|Video Games]].
