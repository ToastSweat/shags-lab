# Bytes

A **byte** is a small unit of computer data made from eight bits. Files, downloads, and drive capacities are usually measured in bytes or larger units built from them. A lowercase “b” often means bits; an uppercase “B” means bytes, so a network speed and a file size aren't necessarily using the same unit.

In the [[Booru Image Downloader Home|image archive]], “the same bytes” means the same stored image data. Copying an image into several folders normally stores that data several times. [[Wiki/hard links|hard links]] provide several names for one stored file instead.

Bytes aren't the same as visible characters, either. [[Wiki/Unicode|Unicode]] text can use multiple bytes for a single character, depending on its encoding. For much larger storage totals, see [[Wiki/terabytes|terabytes]].
