# Binary Clock

A **binary clock** shows the time using lights or bits instead of ordinary clock digits. Each position is either on or off. Reading it means adding the values of the lit positions.

There are different layouts. Some encode whole hours, minutes, and seconds; others encode each decimal digit separately. The labels and arrangement tell you which system you're looking at. It looks mysterious until you know the pattern, then it's just a clock with extra homework.

The [[iCue Binary Clock Widget Home|iCue Binary Clock Widget]] brings that idea to the [[Corsair Xenon Edge Home|Corsair display]]. Its project note shows several customization options, including a stripped-down view with nothing but bits.

Binary is also the foundation underneath ordinary computer data. [[Wiki/bytes|bytes]] bundle bits into useful units; a binary clock makes those usually invisible on/off values visible.
