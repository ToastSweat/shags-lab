# GitHub

**GitHub** is a service for hosting [[Wiki/Git|Git]] repositories and collaborating on projects. It can hold code, documentation, issue discussions, and release files. Git does the version tracking; GitHub provides an online home and surrounding tools.

Several lab project pages link their public source repositories, including the [[Booru Image Downloader Home|image downloader]] and [[iCue Binary Clock Widget Home|binary clock]]. The [[Obsidian-to-Website-General-Guide|website guide]] also describes keeping the full vault in a private repository while publishing only selected generated pages.

Public and private are separate decisions. A public website doesn't require exposing the full source vault, and a repository being private doesn't make leaked [[Wiki/credentials|credentials]] good practice.

A hosted copy is useful off-machine protection, but it isn't a complete backup policy. Uncommitted files, private assets, databases, and restore procedures need their own consideration; see [[Wiki/backups|backups]].
