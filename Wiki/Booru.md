# Booru

A **booru** is an imageboard organized around searchable tags. Rather than putting each image into one folder, a post can have tags for its artist, characters, source material, and whatever else describes it. That makes “show me this character by this artist” a natural kind of search.

The word describes a style of site, not one particular service. Rules, content, and available [[Wiki/API|API]] features vary between boorus. [[Wiki/Rule34|Rule34]] is the one used by the [[Booru Image Downloader Home|image downloader]] documented here; it contains adult material.

The downloader turns those online tag searches into a local archive. Because one image can match several categories, [[Wiki/hard links|hard links]] let it appear in multiple folders without storing the same image data repeatedly. Tags describe the collection; the filesystem handles where it appears.
