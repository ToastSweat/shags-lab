# Git

**Git** is a version-control tool: it records deliberate snapshots of files so you can inspect changes, recover older versions, and keep track of how a project developed. It works locally; it isn't the same thing as [[Wiki/GitHub|GitHub]].

For [[Obsidian Vault to Website Home|this vault's website workflow]], Git keeps the history of the source notes and the material used for deployment. That makes it easier to see what changed instead of guessing which copy of a file is newer.

Git doesn't automatically record every unsaved or uncommitted change, and a local repository isn't protection against losing the whole drive. Off-machine copies and proper [[Wiki/backups|backups]] still matter.

It also remembers more than the current visible files. Accidentally committing [[Wiki/credentials|credentials]] can leave them in history after deletion. Private data needs deliberate handling before anything is shared or published.
