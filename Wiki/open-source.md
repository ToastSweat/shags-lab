# Open-source

**Open-source** software comes with source code under a license that permits people to inspect, use, modify, and redistribute it according to that license's terms. It's more specific than “free to download” or “the code happens to be visible.”

For the [[Keychron C100 Custom Firmware Home|C100 keyboard project]], access to Keychron's [[Wiki/QMK|QMK]] source made it possible to build a different layout instead of waiting for the launcher to gain more features. [[Wiki/Hermes Agent|Hermes Agent]] is another open-source tool used in the lab.

Open source doesn't mean every build is safe, supported, or compatible with your hardware. You still need the right version, sensible tests, and a recovery plan.

[[Wiki/GitHub|GitHub]] hosts many open-source projects, but not everything hosted there is open source. The license matters, and private [[Wiki/credentials|credentials]] never belong in a public source release.
