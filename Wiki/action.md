# Action

Action is the gap between the strings and the frets. Low action takes less effort to press down; higher action gives the strings more room to move before they buzz against a fret. Neither is automatically better. The useful setting is the one that feels comfortable and behaves with the way you actually play.

On [[BASS VI - Penny Home|Penny]], the action already felt good during the [[Bass VI - Penny - First Time Setup|first setup]], so there was no reason to start turning screws just because the strings were off. That is a perfectly valid setup decision.

The [[Wiki/Bridge|Bridge]] affects string height, while the [[Wiki/Truss Rod|Truss Rod]] changes the neck's slight curve. Those are related jobs, not interchangeable fixes. [[Wiki/Tuning|Tuning]] and string changes can affect the feel too, so check the whole instrument before chasing one measurement.
