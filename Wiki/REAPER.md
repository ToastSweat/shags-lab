# REAPER

**REAPER** is a digital audio workstation: software for recording, editing, arranging, and mixing music. It handles recorded audio as well as [[Wiki/MIDI|MIDI]] performances that tell instruments what to play. Think recording studio on a computer, with fewer cables to trip over.

It can also run scripts that automate editing jobs. That's the useful bit behind my [[Projects/Reaper Drum Humanizer/Reaper Drum Humanizer Home|Drum Humanizer]]: select an imported MIDI drum part, run the script, and let it adjust timing and hit strength according to a simple model of a drummer's limbs.

REAPER is the workshop; the humanizer is a tool running inside it. The project doesn't replace REAPER or generate a finished drum recording by itself. It changes the performance instructions that a drum instrument will turn into sound.
