**9.27.2026 - I Gave Shag's Lab a Tune-Up**

Today was mostly a cleanup day for Shag's Lab.

The site has been working, but the vault has grown enough that some of the little inconsistencies were starting to matter. Different project names, empty properties, status values that did not quite mean the same thing, a few weird folder names, and some pages that were technically public even though they were still empty.

So I finally sat down and cleaned the whole thing up.

The biggest change was adding a new page type:

```yaml
type: project-parent
```

This is for things that are not really projects themselves, but are containers for multiple projects.

For example, **Keychron C100** is now a parent, while things like **Keychron C100 Custom Firmware** and **Keychron C100 Custom Keycaps** are the actual projects underneath it.

The same idea now works for things like **Instruments** and **My Mini Retro Television**.

That already makes the Explorer feel a lot more sane.

I also went through the metadata across the vault and standardized the headers. Projects now have consistent project names and statuses, empty placeholder properties were removed, Wiki pages were cleaned up, a few old project names were normalized, and some accidental copy/paste nonsense got fixed.

There were, naturally, a couple casualties.

Two Teenage Engineering synth folders got mangled by an encoding problem during the cleanup and briefly showed up twice in the website Explorer with names like:

```text
EPâ€“40
```

Very futuristic.

Those were cleaned up too, and the new metadata validator actually caught the problem before one of the broken versions could quietly become part of the site.

That validator is probably one of my favorite changes from today.

The publishing script now checks the vault before Quartz builds and complains if I do something stupid like:

- forget a required project name
- use an invalid status
- mismatch an update date
- publish an empty page
- create inconsistent project metadata

That means Shag's Lab is getting to the point where the tooling is starting to protect the structure instead of me having to remember every rule manually.

I also added a **Wiki** section, which I have wanted from the beginning. It is still pretty sparse, but now there is a real place for notes that are not projects or chronological updates.

Oh, and the website finally has a visitor counter.

Nothing ridiculous. Just:

```text
Shag's Lab · 5 visitors
```

Nice and boring.

There are still a few things I want to revisit later:

- sort projects more intentionally by status
- formally define what every status means
- keep improving the parent/project hierarchy
- clean up old broken/private links
- make an actual good Shag's Lab logo

But the important part is that the site feels a lot less like a pile of Markdown files now.

It is starting to feel like an actual little system.

Which was kind of the whole point.
