## Star Wars Battlefront II Dedicated Server
[[Projects/Star Wars Battlefront II Dedicated Server/Star Wars Battlefront II Dedicated Server Home|Star Wars Battlefront II Dedicated Server Home]]
This one is frustrating.

I have been trying to make it so that the server is essentially PvE. I want to lock the human players on one team and make it impossible to switch sides. To take that further I want the Human team to be configurable, so that I could play Geonosis as the Clones, then Kashyyyk as the Separatist Droid Army.

This has been a PITA, and I don't mean the tasty kind.

Lots of old forum posts saying do it this way and that, yet none are really, truely working.

I may have stumbled upon a way to do it though.

You CAN auto assign players to teams, this even distributes the players amongst the teams, you cannot pick you team and you cannot switch teams after you have been assigned.

Well YOU can't the [[Wiki/SWBFIIAdmin|SWBFIIAdmin]] control panel can switch players between teams at will.

So if I can put the server on Auto Assign players, easy, and then enforce the teams with a config file in the mission startup, not with a command or function after the game has stated, then I think there's a possibility this could work!

The ultimate goal is to make our own campaign, but we'll see where I go with this.

God can't keep me away from modding the Renderware engine, it seems.

OH!
I almost forgot the best part!

I had an issue where I could not use [[Wiki/Remote Desktop Connection|Remote Desktop Connection]] because the game has to 'tunnel' through the player and that requires [[Wiki/Chrome Remote Desktop|Chrome Remote Desktop]].

Well Long story short, I was using the same user account for both of those remote connectors and that's what was breaking the tunnel. Making a new user account just for the the game server to run fixed it no problem!
