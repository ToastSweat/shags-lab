## 🔬 The Lab

A lot of my personal projects exist somewhere between **software engineering**, **digital archaeology**, and **"this would be cool."**

Recent adventures include:

**🔐 Safe Cracker**  
A daily Discord game built as a Discord Activity. Guess the combination. Beat the clock. Try not to embarrass yourself in front of everyone else.

**⚔️ Star Wars Battlefront II Server Infrastructure**  
Dedicated server hosting, Discord integration, stats, leaderboards, backups, automation, and various attempts to convince a game from 2005 that it lives in the future now.

**👾 Game Boy Development**  
Building an actual game for the original Game Boy using GBDK, because apparently modern hardware was too convenient. Also total bucket-list item.

**⌨️ Custom Keyboard Firmware**  
Bought a strange keyboard. Didn't like what the software let me do. Ended up modifying the firmware instead.

As one does.

**📺 Retro Media Projects**  
Turning tiny retro televisions, USB drives, old commercials, cartoons, bumpers, and questionable amounts of organization into miniature recreations of channel-surfing television.

**🧠 Digital Garden / Project Archive**  
Building a Markdown-powered archive of my projects so Future Me can eventually understand what Past Me was thinking.

Good luck, Future Me.
