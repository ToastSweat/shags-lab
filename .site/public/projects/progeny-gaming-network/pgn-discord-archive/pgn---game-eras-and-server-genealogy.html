PGN Game Eras and Server Genealogy

This file separates three things that raw Discord statistics easily confuse:

  1. a game was mentioned,
  2. PGN was actively playing a game together,
  3. PGN operated or seriously planned shared infrastructure for the game.

A Steam link is weak evidence of a clan era. Repeated direct invitations are stronger. A dedicated channel with hundreds of messages, server settings, and uptime problems is very strong.

The recurring families

MTA / GTA multiplayer

MTA → SAES/WSS/Helvete → FiveM → GT-MP → alt:V → FiveM zombie work → modern GTA-server discussions

This is PGN’s longest technical lineage. What persists is not one mod but a preferred shape of multiplayer: social open-world play, custom jobs, groups/gangs, scripting, server ownership, and the ability to make ridiculous systems the base game never intended.

The 2020 Hogwarts RP work demonstrates both the power and limitation of the lineage. PGN could build complex systems inside MTA, but the work remained tied to an aging mod and outside intellectual property. The Unity pivot later that year is therefore not a rejection of MTA; it is an attempt to carry the skills somewhere more durable.

Minecraft / Dargeath

Minecraft → Dargeath → lost backups → repeated nostalgia → vanilla returns → Dargeath 17.0

Minecraft is the purest shared-place game in PGN history.

Dargeath gives that pattern a named myth. Its loss turns it from old software into a lost world. Later Minecraft revivals repeatedly inherit the emotional goal even when they cannot inherit the original data.

Survival servers

ARK → 7 Days to Die → Grounded → Valheim → Palworld / Enshrouded / The Isle / ARK returns → Dune

These games generate the clearest communal eras because they create persistent places and maintenance obligations.

They also generate the most predictable PGN thought:

should we make a server?

Old-game resurrection

By 2026, resurrecting games nobody has touched in years is literally part of PGN’s own About-page description.

Battlefront II Classic is the culmination: an old game becomes the base for a modern database, website, progression system and Discord project.

Strong eras

Overwatch — late 2016 into 2018

The first major game visible after Discord begins. The archive explicitly refers to a Progeny Overwatch team and contains repeated invitations, season chatter and cosmetics.

ARK — January 2017

Server admin, RCON, updates, downtime and all-night taming make this a strong shared-world era.

PUBG — spring/summer 2017

One of the strongest invitation patterns in the early archive.

Factorio — July 2017

Short, concentrated and clearly multiplayer.

Fortnite — 2017–2018

PGN catches Fortnite before and after Battle Royale arrives.

Crossout — 2018 and 2023

A true recurring era. The later revival even becomes a recruiting funnel into PGN Discord roles.

7 Days to Die — May 2018

A compact server era followed almost immediately by interest in custom scripting.

MTA / SAES / Hogwarts — 2020

Heritage revival, active scripting, and a substantial custom server experiment.

Grounded — August 2022

Repeated organized sessions and shared-world excitement.

Valheim — 2022/2023, then major 2025 return

The idea survives across years before becoming a visible settlement/server era.

Helldivers II — March–May 2024

The strongest dedicated game thread of the modern archive.

Palworld — January–February 2024

A classic hot-and-fast shared-server phase.

The Isle — March 2025

Discord becomes field navigation: coordinates, player locations and server details.

Dune: Awakening — 2025 play, 2026 infrastructure

The later private-server work turns it into one of PGN’s technically richest hosting efforts.

Star Wars: Battlefront II Classic — 2026

The server is funny. The surrounding roadmap is historically significant.

PGN begins by running servers for games and gradually evolves toward building systems around games until the surrounding project is almost as large as the game itself.
